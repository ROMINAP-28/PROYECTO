# Módulo de Ingeniería de Software — TRAVELINK 📐

Este directorio consolida las especificaciones técnicas, procesos de negocio, diseño arquitectural, modelo de persistencia, interfaz de usuario y catálogo de código fuente del sistema **TRAVELINK**.

- **Procesos de Negocio:** [`procesos/`](procesos/) (BPMN, reservas, liquidación de comisiones y aprobación de agencias)
- **Diseño del Sistema:** [`diseno/`](diseno/) (Patrones de diseño MVC, Service Layer, Repository y Adaptadores)
- **Base de Datos:** [`base-datos/`](base-datos/) (Modelo relacional, diccionario de 18 tablas e índices)
- **UX / UI:** [`ux-ui/`](ux-ui/) (Diseño frontend desacoplado, estilos modulares y accesibilidad)
- **Reportes:** [`reportes/`](reportes/) (Especificación de generación PDF con OpenPDF y libros Excel con Apache POI)
- **Código Fuente:** [`codigo-fuente/`](codigo-fuente/) (Estructura de paquetes `com.travelink.*` y catálogo de clases)
