## 1. Descripción de la Vulnerabilidad
En el método `verificarPassword(Usuario usuario, String rawPassword)` de la clase `UsuarioServicioImpl`, existe una bifurcación condicional que valida la autenticación de usuarios de forma exitosa si el correo coincide con una lista estática de cuentas (`turista@travelink.com`, `admin@travelink.com`, `turista@gmail.com`, `agencia@travelink.com`) siempre que la contraseña ingresada no esté vacía o coincida con un valor predeterminado, sin ejecutar la verificación criptográfica contra el hash BCrypt almacenado en la base de datos.

## 2. Evidencia en Código Fuente
Extracto de [`UsuarioServicioImpl.java`](file:///d:/ProyectosU/PROYECTO/Springboot/src/com/travelink/servicio/impl/UsuarioServicioImpl.java#L119-L127):

```java
// Líneas 119-127
if (usuario.getCorreo() != null && (
        usuario.getCorreo().equalsIgnoreCase("turista@travelink.com") ||
        usuario.getCorreo().equalsIgnoreCase("admin@travelink.com") ||
        usuario.getCorreo().equalsIgnoreCase("turista@gmail.com") ||
        usuario.getCorreo().equalsIgnoreCase("agencia@travelink.com")
)) {
    // Si la contraseña ingresada es la contraseña temporal conocida, permitir
    if ("Turista#123".equals(rawPassword) || "Admin#123".equals(rawPassword) || rawPassword.length() > 0) {
        return true;
    }
}
```

## 3. Causa Raíz
Prácticas inseguras de depuración y pruebas locales dejadas en código de producción, permitiendo que cualquier atacante que conozca o adivine una de esas direcciones de correo obtenga una sesión autenticada válida ingresando cualquier carácter no vacío (`rawPassword.length() > 0`).

## 4. Impacto
- **Confidencialidad:** Total (Acceso a paneles administrativos y datos personales de usuarios).
- **Integridad:** Total (Modificación no autorizada de reservas, comisiones y catálogos de tours).
- **Disponibilidad:** Alta (Capacidad de deshabilitar cuentas y cancelar transacciones).

## 5. Recomendación de Mitigación
Eliminar de inmediato el bloque de bypass hardcodeado y delegar la validación al `PasswordEncoder` estándar de Spring Security:

```java
@Override
public boolean verificarPassword(Usuario usuario, String rawPassword) {
    if (usuario == null || rawPassword == null) {
        return false;
    }
    String storedHash = usuario.getPasswordHash();
    if (storedHash == null || !storedHash.startsWith("$2a$") && !storedHash.startsWith("$2b$")) {
        return false;
    }
    return passwordEncoder.matches(rawPassword, storedHash);
}
```
