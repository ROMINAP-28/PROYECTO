## 1. Descripción de la Vulnerabilidad
En la cadena de filtros de seguridad `filterChain` de `SecurityConfig.java`, se configuran reglas `ignoringRequestMatchers` que desactivan completamente la validación de tokens anti-CSRF para rutas transaccionales que ejecutan modificaciones de estado permanentes, tales como creación de reservas, pagos, cancelaciones, registro de reseñas y endpoints administrativos.

## 2. Evidencia en Código Fuente
Extracto de [`SecurityConfig.java`](file:///d:/ProyectosU/PROYECTO/Springboot/src/com/travelink/config/SecurityConfig.java#L66-L91):

```java
.csrf(csrf -> csrf
    .csrfTokenRepository(csrfTokenRepository())
    .csrfTokenRequestHandler(requestHandler)
    // Desactivación indiscriminada de CSRF en endpoints con efectos secundarios
    .ignoringRequestMatchers(
        "/api/auth/**",
        "/api/registro",
        "/api/guardar_reserva",
        "/api/cancelar_reserva",
        "/api/calificar",
        "/api/pagos/**",
        "/api/admin/**",
        "/api/agencia/**",
        "/api/usuario/**"
    )
)
```

## 3. Causa Raíz
Dificultades en la sincronización de tokens `XSRF-TOKEN` entre clientes web y servicios REST durante el desarrollo, resultando en la desactivación del mecanismo de defensa en lugar de implementar el patrón `CookieCsrfTokenRepository.withHttpOnlyFalse()` con envío adecuado de cabeceras `X-XSRF-TOKEN`.

## 4. Impacto
Si el usuario víctima mantiene una sesión activa en el navegador e interactúa con un enlace o formulario embebido en un sitio de terceros, el navegador enviará automáticamente las cookies de sesión (especialmente dado que `SameSite` no está forzado a `Strict`), ejecutando pagos, cancelaciones o cambios de rol sin el consentimiento del usuario.

## 5. Recomendación de Mitigación
1. Requerir token CSRF para todos los métodos mutantes (`POST`, `PUT`, `DELETE`).
2. Mantener la exención únicamente en rutas de autenticación sin estado si se utiliza JWT, o asegurar la validación estricta de cabeceras en API REST:

```java
.csrf(csrf -> csrf
    .csrfTokenRepository(CookieCsrfTokenRepository.withHttpOnlyFalse())
    .csrfTokenRequestHandler(new CsrfTokenRequestAttributeHandler())
    .ignoringRequestMatchers("/api/auth/login", "/api/eventos/poll")
)
```
