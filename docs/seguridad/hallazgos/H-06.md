## 1. Descripción de la Vulnerabilidad
El servicio de calificaciones y comentarios almacena el contenido del campo `comentario` en la base de datos sin sanitización ni validación de caracteres peligrosos. Posteriormente, el frontend en JavaScript renderiza este texto utilizando asignaciones inseguras mediante `innerHTML` y template literals en lugar de `textContent` o codificación HTML contextual.

## 2. Evidencia en Código Fuente

### Backend ([`CalificarHandler.java`](file:///d:/ProyectosU/PROYECTO/Springboot/src/com/travelink/controlador/turista/CalificarHandler.java#L220-L223)):
```java
// El comentario se persiste sin escapar tags HTML o caracteres de script
String comentario = (String) payload.getOrDefault("comentario", "");
calificacion.setComentario(comentario);
calificacionRepositorio.save(calificacion);
```

### Frontend ([`detalle.js`](file:///d:/ProyectosU/PROYECTO/Springboot/resources/static/js/turista/detalle.js#L343-L355)):
```javascript
// Renderizado vulnerable con innerHTML
contenedorComentarios.innerHTML += `
    <div class="comentario-item">
        <strong>${c.nombreUsuario}</strong>
        <p>${c.comentario}</p> <!-- INYECCIÓN DIRECTA EN EL DOM -->
    </div>
`;
```

## 3. Causa Raíz
Falta de una política de sanitización en el backend (ej. OWASP Java HTML Sanitizer) combinada con el uso de APIs del DOM propensas a XSS (`element.innerHTML`) en el cliente.

## 4. Impacto
- Ejecución de código JavaScript arbitrario en el navegador de cualquier usuario o administrador que visite la página del tour (ej. `detalle.html?id=100`).
- Robo de tokens de sesión almacenados en `localStorage` o cookies sin flag `HttpOnly`.
- Redirección forzada de usuarios a páginas de phishing y alteración visual del contenido del portal.

## 5. Recomendación de Mitigación
1. **Frontend:** Usar `textContent` o crear nodos del DOM seguros:
   ```javascript
   const pComentario = document.createElement('p');
   pComentario.textContent = c.comentario; // Codificación segura automática
   divItem.appendChild(pComentario);
   ```
2. **Backend:** Limpiar el texto antes de persistirlo utilizando una biblioteca de sanitización:
   ```java
   PolicyFactory policy = Sanitizers.FORMATTING.and(Sanitizers.LINKS);
   String safeComentario = policy.sanitize(rawComentario);
   ```
