## 1. Descripción de la Vulnerabilidad
La aplicación no emite cabeceras HTTP defensivas estándar requeridas por la industria para mitigar ataques client-side. El escaneo con OWASP ZAP confirmó la ausencia de `Content-Security-Policy` (CSP), `Permissions-Policy`, y cabeceras de aislamiento cross-origin (COEP, COOP, CORP). Adicionalmente, `SecurityConfig.java` desactiva explícitamente la protección de caché en endpoints sensibles mediante `headers.cacheControl(cache -> cache.disable())`.

## 2. Evidencia en Código y Escáner

### Código Fuente ([`SecurityConfig.java`](file:///d:/ProyectosU/PROYECTO/Springboot/src/com/travelink/config/SecurityConfig.java#L191-L196)):
```java
// Desactivación intencional de control de caché
.headers(headers -> headers
    .frameOptions(frame -> frame.sameOrigin())
    .cacheControl(cache -> cache.disable()) // RIESGO: Respuestas sensibles pueden almacenarse en proxies/navegadores
)
```

### Evidencia Dinámica (OWASP ZAP Baseline):
- `Plugin ID 10038`: Content Security Policy (CSP) Header Not Set (Medium).
- `Plugin ID 90003`: Sub Resource Integrity Attribute Missing (Medium).
- `Plugin ID 10063`: Permissions Policy Header Not Set (Low).
- `Plugin ID 90004`: Cross-Origin-Opener-Policy Header Missing (Low).

## 3. Causa Raíz
Desactivación explícita de directivas de caché y omisión de la configuración del bloque `.contentSecurityPolicy(...)` y `.permissionsPolicy(...)` en el DSL de Spring Security.

## 4. Impacto
- Almacenamiento en memoria intermedia o disco local de respuestas con datos de usuarios en terminales compartidos.
- Ausencia de barreras de contención ante explotación de ataques XSS (el navegador no restringe la carga de scripts externos o dominios de exfiltración).

## 5. Recomendación de Mitigación
Habilitar las cabeceras de seguridad y CSP en `SecurityConfig`:

```java
.headers(headers -> headers
    .contentSecurityPolicy(csp -> csp
        .policyDirectives("default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; font-src 'self';")
    )
    .frameOptions(frame -> frame.deny())
    .xssProtection(xss -> xss.headerValue(XXssProtectionHeaderWriter.HeaderValue.ENABLED_MODE_BLOCK))
    .contentTypeOptions(Customizer.withDefaults())
    .cacheControl(Customizer.withDefaults()) // Habilitar no-cache, no-store, must-revalidate
    .permissionsPolicy(permissions -> permissions.policy("geolocation=(), microphone=(), camera=()"))
)
```
