## 1. Descripción de la Vulnerabilidad
En los métodos encargados de actualizar (`PUT /api/calificar`) o suprimir (`DELETE /api/calificar`) reseñas turísticas en `CalificarHandler.java`, la aplicación recibe directamente el `idCalificacion` en el payload o parámetro sin validar si el registro pertenece al usuario autenticado en la sesión actual. Cualquier usuario autenticado puede alterar el texto, puntuación o borrar las reseñas dejadas por otros turistas o agencias.

## 2. Evidencia en Código Fuente
Extracto de [`CalificarHandler.java`](file:///d:/ProyectosU/PROYECTO/Springboot/src/com/travelink/controlador/turista/CalificarHandler.java#L80-L95):

```java
// Método de actualización de calificación
int idCalificacion = (int) payload.get("idCalificacion");
Calificacion calificacion = calificacionRepositorio.findById(idCalificacion)
    .orElseThrow(() -> new RuntimeException("Calificación no encontrada"));

// VULNERABILIDAD: No se compara calificacion.getUsuario().getIdUsuario() con el usuario en sesión
calificacion.setPuntuacion((int) payload.get("puntuacion"));
calificacion.setComentario((String) payload.get("comentario"));
calificacionRepositorio.save(calificacion);
```

## 3. Causa Raíz
Falta de verificación de propiedad del objeto (Object Ownership Validation) en la capa de servicio previa a la ejecución de operaciones de modificación o borrado en la base de datos.

## 4. Impacto
- Manipulación fraudulenta de la reputación comercial de agencias y tours turísticos.
- Sabotaje y censura no autorizada de opiniones legítimas entre competidores.

## 5. Recomendación de Mitigación
Verificar que el usuario autenticado sea el creador original de la calificación o posea privilegios de administración antes de autorizar la mutación:

```java
Integer currentUserId = SecurityUtils.getAuthenticatedIdUsuario()
    .orElseThrow(() -> new ResponseStatusException(HttpStatus.UNAUTHORIZED));

Calificacion calificacion = calificacionRepositorio.findById(idCalificacion)
    .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND));

boolean esPropietario = calificacion.getUsuario().getIdUsuario().equals(currentUserId);
boolean esAdmin = SecurityUtils.hasRole("ROLE_ADMIN");

if (!esPropietario && !esAdmin) {
    throw new ResponseStatusException(HttpStatus.FORBIDDEN, "No tiene permisos para modificar esta reseña");
}

calificacion.setPuntuacion(nuevaPuntuacion);
calificacion.setComentario(nuevoComentario);
calificacionRepositorio.save(calificacion);
```
